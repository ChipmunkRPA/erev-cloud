- SPEC-Q-79 (EKC-4 `first_open_period_on_or_after(entity, book, d)` vs ENGINE_SPEC §8.2 `(entity, d, book)`): BUILD_SPEC order; earliest period ending on or after d in state `open` or `reopened`, else None; a missing book state raises `ENGINE_INVARIANT_VIOLATED` (CV-13); `month_ends_between` returns 0 when b < a.
