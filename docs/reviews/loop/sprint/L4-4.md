### What was built

- `backend/erev_api/explain/service.py`:
  - `build_explain` (PLF-20) is unchanged; its depth check is now `_check_depth`.
  - `explain_measure` resolves a figure to its contract version, its stored `calc_trace` (hash-checked by `store.trace_from_row`) and a root node. It returns API-S-Explain: `object`, `value`, `context`, `calc_trace_id`, `engine_version`, `root_node_id`, `nodes` (to `depth` levels), `narrative` (only `NARRATIVES` through `render`), `history` and `drill`.
  - `value` is the stored column when the object stores the figure, else the node value: API-S-Money for a figure with a currency, a decimal string otherwise.
  - Resolution by object type:
    - `schedule_line` (measure `amount`): `trace_node_id`.
    - `subledger_line` (measure `amount`): `trace_node_id`, or the `posting_delta` node behind a `posting_target` id (L4-4-Q-12).
    - `obligation_version`: `trace_nodes[measure]`, or `<measure>:<subject key>:<period>` with `period`. `revenue` with `period` is the single `revenue_by_cause` node of the period.
    - `obligation`: the obligation version of the latest contract version in `book` (default primary), recorded by `known_at` when sent.
    - `contract_version`: `<measure>:<group code>:<period or '-'>`.
    - `contract_version_balance`: `<measure>:<contract external id>@<entity code>:<period>`, the latest period without `period`.
    - `journal_line`: 404 (L4-4-Q-13).
    - Measure aliases of SCREENS §6.3: `revenue_to_date`, `billed_to_date`, `scheduled`, `awaiting_trigger`, `selected_ssp`.
  - `history`: one query with `jsonb_path_query_first` over `calc_trace.trace` reads the root node's value in each contract version of the group and book, up to the explained version. The versions in which the value changed are listed newest first, with `delta`.
    - `cause` is the type of the latest causing event the caller can see (by `record_seq`), or `RECOMPUTE` when the version has no causing event.
    - `estimate_version_pair` compares the `estimate_version_ids` pinned by consecutive computations (L4-4-Q-11).
  - `drill`: `contract_href`, `obligation_href`, `schedule_lines_href` (`/contracts/{id}/schedule?book=`) and `subledger_lines_href` (`/subledger-lines?contract=&book=&period=`); `source_rows` [] (L4-4-Q-14).
  - Source inputs: `href` `/api/v1/events/{id}` for `contract_event` references `<external id>/EV-<n>`, else null.
  - `verify_measure`: `reevaluate(trace)[root]` against the stored value, compared exactly as decimals.
  - `calc_trace_out`: API-S-CalcTrace. `calc_trace` is RLS-T, so the route answers 404 unless the caller's scope shows a member contract of the trace's group.
- `backend/erev_api/schemas/explain.py`: `ExplainOut`, `ExplainObjectOut`, `ExplainNodeOut`, `ExplainNodeInputOut`, `ExplainSourceInputOut`, `ExplainHistoryItemOut`, `EstimateVersionPairOut`, `ExplainDrillOut`, `ExplainSourceRowOut`, `ExplainVerifyOut`, `CalcTraceOut`, `ExplainObjectType`.
