- **read**: this lane read the lines the row cites. For a NOT BUILT row the absence was tested in more than one form: the symbol the order would add, the name of its witness, its document row, and the item's or the clause's name in the messages of the commits reachable from the head.
- **checked**: an independent reader read the product line and this lane did not, or opened it only to see that it is there. For a BUILT row the cell names the reader and, for the third reader, the line it read. For an open row the words "by the fourth reader" mark what rests on that reader's reading or searches.
- **log**: the log itself says so, in the same or a later ruling.

The basis "cited" of the first edition — a commit names the clause and a file cites it, found by a script and opened by nobody — is gone: every such row has been read by a reader.

3. **Anchors.** 1,694 paths, line numbers and commit ids in the rows were checked by a script against the head the row was read on: the path exists, the line is inside the file, the commit is an ancestor. The script does not check what a line says.
