They were collected through the registry on `37b0c0ee`: 315 tests. The outcome is that of full10 (head `de3a93ed`), the last whole-suite run that had finished when this file was written, unless the cell says otherwise. A test that is not in that run's tree has no outcome in a whole-suite run that ended; where the later run full11, which was stopped, holds it, the cell says so (section 5).

**Verdict.** It is given on the clauses of the row and of the requirements the row names.
- BUILT: every clause read is enforced on every path found in the code.
- PARTLY: at least one clause, or one path to the thing controlled, is not enforced. The cell says which. PARTLY is strict: it does not say that the control is absent.
- NOT BUILT: no enforcing code for the row's main clause.

Four conventions. A finding counts against a row when it leaves a clause of that row unenforced on some path; F-12 is cited in three rows and counts against CTL-007 and CTL-013, whose clauses it goes round, and not against CTL-046, whose clauses are about making a void and hold — there the finding is that a void once made can be undone under a lesser approval, which the row does not name. A verdict with a qualification (CTL-032, 037, 039, 044) is counted by its first word. A path that a ruling leaves open on purpose does not make a row PARTLY; the cell names the ruling (CTL-044); a gap that a ruling orders closed and that is not yet built does. The evidence column of a row is not a clause: where the evidence a row names is not produced, or not on every path, the cell says so and the verdict does not change (CTL-012, CTL-023). This lane did not check the evidence of every row.

**Evidence.** File and line on `37b0c0ee`. A finding of section 4 is cited by its number (F-n). Where a gap was already ruled, the ruling or the item is named instead; such gaps are not findings of this inventory.
