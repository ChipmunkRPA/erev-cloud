## Release finalization and independent approval

Added a finalization command that verifies attached report bytes before taking the tenant
population fence, then compares locked versions and reassesses the current population.
PASSED sets the accepted attempt and enablement together with the sealed processing queue;
MINOR differences become FAILED; MAJOR differences submit a SYSTEM-prepared, non-auto-approved
request with retained before/after report values. Request content binds the dataset, report,
release identity and frozen required entity set. Existing approval APIs and inbox labels now
recognize ENGINE_RELEASE_VALIDATION, routed to period.lock for every required entity.

Approval rechecks frozen file integrity using the approved request's authority (not unrelated
report export permissions), then reassesses population under the fence and enables/seeds in
one transaction. Only accepted DIFFERENCES groups are dirtied; existing dirty timestamps survive.
Rejection does not enable. Invalidated/withdrawn requests move PENDING_APPROVAL to INCOMPLETE.
Supersession locks request, parent and attempt in decision order and voids STALE_SUBJECT before
allowing a replacement attempt. Revision 0169 adds the enum, transition and register filter.
