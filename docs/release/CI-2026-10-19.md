## Attempt report attachment

then attempt locks serialize it with supersession and acceptance. It verifies the
successful report/job identity, current caller grants, exact frozen source binding,
recomputed rows/totals and retained output integrity. An existing reference cannot be
replaced; an identical retry performs verification without rewriting the row.

## Tenant population transaction fence

Migration 0165 installs BEFORE INSERT/UPDATE/DELETE guards on the 12 tables used by
`validation_population.read`, including inherited partition triggers. Each writer takes
a shared transaction advisory lock keyed by tenant. `validation_fence.hold` takes the
exclusive side before final validation locks; both sides use try-locks to refuse contention
without waiting under other row locks. The helper requires full entity scope and READ
COMMITTED so the subsequent population read sees a fresh snapshot. Commit/rollback
releases the reservation. This does not yet implement the final acceptance command.

cause enum. The database verifies posting/computation/group/release ownership, accepted
